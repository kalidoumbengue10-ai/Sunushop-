# Noto Sans

Les fichiers `NotoSans-Regular.ttf` et `NotoSans-Bold.ttf` proviennent du
dépôt officiel [`notofonts/noto-fonts`](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans).

Ils sont utilisés côté serveur pour incorporer une police Unicode dans les
reçus PDF de commande. Leur licence SIL Open Font License 1.1 est conservée
dans `Noto-Sans-OFL.txt`.
