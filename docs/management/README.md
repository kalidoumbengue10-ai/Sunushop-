# Assistant Manager SunuShop

Ce dossier est le centre de pilotage du projet.

## Fichiers

- `PROJECT-STATUS.md` : état actuel et objectif immédiat.
- `BACKLOG.md` : priorités et tâches à suivre.
- `DECISIONS.md` : décisions prises ou en attente.
- `REPORT-TEMPLATE.md` : structure obligatoire des rapports.
- `reports/` : rapports datés créés automatiquement à 8 h et 18 h.

## Fonctionnement

L’Assistant Manager observe le dépôt et la documentation, mais ne modifie pas le code applicatif sans demande explicite. Il peut mettre à jour les documents de ce dossier pour assurer le suivi.

Les rapports automatiques sont enregistrés localement dans `docs/management/reports/`. Dans le terminal Hermes, ils ne sont pas envoyés comme notifications. Ils restent consultables dans ce dossier et via la liste des tâches cron Hermes.
