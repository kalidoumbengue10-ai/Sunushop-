# Restaurant sénégalais fictif

Landing page autonome pour **Kër Ndar**, un concept de restaurant sénégalais à Dakar.

## Démarrer le projet

```bash
npm install
npm run dev
```

Puis ouvrir `http://localhost:3000`.

## Structure

- `app/` : page et styles du site
- `public/images/` : visuels gastronomiques
- `docs/` : direction artistique et design system

Les coordonnées, horaires et informations commerciales indiqués « à confirmer » doivent être remplacés avant publication réelle.
